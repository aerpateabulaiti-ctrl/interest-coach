# 需求与升级范围

## 课题要求

使用 TypeScript 与 Modern.js 搭建前后端一体应用，完成聊天界面、SSE 输出、模型接入、兴趣教练提示词，并进一步实现 LangGraph Agent、Tavily 搜索、对话持久化和结构化任务视图。交付包括代码、README、技术方案和演示。

本文件是需求摘要，不包含账号或密钥。

## 本轮用户流程

1. 用户创建或选择学习目标，提供当前水平与时间预算。
2. 选择聊天、制定计划或进度复盘，按需开启联网资料。
3. 前端展示实时回答和运行状态；可取消生成。
4. 系统生成计划草案，对结构与预算进行校验。
5. 用户确认草案后才能打卡；保留历史计划。
6. 用户记录任务完成情况与收获，教练根据实际进度复盘。
7. 用户可以重新打开、导出或删除目标。

## 验收标准

- 刷新页面及重启服务后，目标、任务和记录仍然存在。
- 未确认草案不能被标记完成；旧版本更新被拒绝。
- 不同匿名浏览器会话不能访问对方的目标。
- 取消或模型错误不会留下半截消息、锁死后续请求。
- 同一个 requestId 不会重复生成；一个目标同时只能运行一轮。
- 真实模式通过服务端访问模型；浏览器资源中不包含模型密钥或服务端代码。
- 演示模式明确标识；无搜索结果时不编造来源。
- 窄屏能够操作对话、历史目标和计划。

## 明确取舍

最初计划使用 MongoDB，本版本改用 SQLite，以获得无需额外数据库服务的可复现体验，并通过事务和索引验证一致性。

本轮优先实现完整业务闭环和可测试边界。完整账号系统、多实例部署、RAG 与公开生产运营不在本轮范围内。
